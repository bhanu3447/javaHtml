## Story and analogy
- Dealership problem: a pre-delivery inspection (PDI) per fuel type. The same five steps (book bay → common checks → model checks → road test → sign off) are copied into `PetrolInspection`, `DieselInspection`, `EvInspection`, and the copies drift (a change request reaches only some copies; one copy signs off before the road test).
- Analogy: a **printed checklist form**. Head office prints the order of the steps; the mechanic fills in only the blanks.
- Framed as "the same goal as Strategy (lesson 01), with inheritance instead of composition".
