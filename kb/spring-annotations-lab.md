## Data model (all in the page script)
- `files`: the demo project, one source of truth for every code box. `Application.java`, `UserController.java`, `UserService.java`, `UserRepository.java`, `User.java`, `CreateUserRequest.java`, `UserResponse.java`, `GlobalExceptionHandler.java`, `application.properties`.
- `render(src, marks)`: tiny highlighter (strings, annotations, comments, keywords, Types) that wraps any line containing one of the `marks` substrings in `.hl`. Marks are substrings, not line numbers, so editing the files does not break highlights (but the test checks every mark still matches).
- `stages`: the 5 flow layers (`file`, `marks`, `annos`, text).
- `A`: the annotation cards: `{n, g (group), t (C|M|F|P), p (package), w (what), s (syntax), a (attributes "name — meaning"), r (related), m (mistake)}`. `byName` maps every individual name (and aliases like `@OneToMany`, `@NotBlank`, `@Min`, `@EnableConfigurationProperties`) to its card. Every `r` entry and every stage chip must resolve in `byName`.
- `scenarios`: `{label, bad, req, res, steps:[[cls, text, file|null, marks|null], …]}`.
- `quiz`: `[question, options, correctIndex, explanation]`.
- `iocSteps` (title, text, code, marks, SVG state), `methods` (9 rows), `SC` ([code, name, meaning, inSpring, starred]), `anat` (part → explanation).
- v3 helpers: `stepper(root, steps, apply, ms)` (generic ◀ ▶ ▶ Play stepper on `[data-t] [data-d] [data-code] [data-pos]`), `cls(id, class, on)`, `moveDot(id, x, y, show)`, `hit(line, mark)`.
- Test hook: `window.SPRING = {files, stages, A, byName, scenarios, quiz, run, openAnno, showFile, buildList, SC, methods, iocSteps, iocShow, scShow, scBuild, hit, proxySteps, dispSteps, txStepsOk, txStepsFail, esActions, n1Run, recallQs, ivQs, bootLines, rj, rjRoutes, rjLayouts, dm, dmShapes, wmShow}`. v4 classes are prefixed `rj-` (map), `dm-` (data morph), `wm-` (modal map) and `.lineage`.

## Rules
- Syntax strings are template literals: write `\${app.name}` for a property placeholder (never a bare `${`), and never `</script>`.
- Adding an annotation: add to `A` (and an alias in `byName` if the card groups several names), make sure its `r` entries exist. Adding a scenario step: `marks` must be substrings of the named file.
