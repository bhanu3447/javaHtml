## Story and analogy
- Dealership problem: discount rules at checkout (none, festival 10%, loyalty Rs 20000 flat with `Math.max(0, …)`, corporate 15%) keep arriving; `Checkout` grows two if / else ladders (`total`, `label`) on a string type code; a typo (`"festive"`) silently gives no discount.
- Analogy: a car's **drive modes** (Eco / Sport / Snow). Driver = client (`main`), car = Context (`Checkout`), "a drive mode" slot = Strategy (`interface Discount`), each mode = ConcreteStrategy, turning the knob = `setDiscount`.
- Beginner terms defined in §01: client, context, strategy, delegation (+ type code in the Pain lab). Links back to P00 `#pf-ocp` and `#pf-refactor`.

### StrategyBefore.java
```java
public class StrategyBefore {
    public static void main(String[] args) {
        long price = 700000;
        Checkout checkout = new Checkout();
        checkout.print(price, "festival");    // Festival 10%: Rs 630000
        checkout.print(price, "loyalty");     // Loyalty Rs 20000: Rs 680000
        checkout.print(price, "corporate");   // Corporate 15%: Rs 595000
        checkout.print(price, "none");        // No discount: Rs 700000
        checkout.print(price, "festive");     // No discount: Rs 700000  (typo: silently no discount)
    }
}

class Checkout {
    // every new offer opens BOTH ladders below, and every tested branch is re-tested
    long total(long price, String offer) {
        if (offer.equals("festival")) return price * 90 / 100;
        else if (offer.equals("loyalty")) return Math.max(0, price - 20000);
        else if (offer.equals("corporate")) return price * 85 / 100;
        else return price;
    }

    String label(String offer) {
        if (offer.equals("festival")) return "Festival 10%";
        else if (offer.equals("loyalty")) return "Loyalty Rs 20000";
        else if (offer.equals("corporate")) return "Corporate 15%";
        else return "No discount";
    }

    void print(long price, String offer) {
        System.out.println(label(offer) + ": Rs " + total(price, offer));
    }
}
```

### StrategyAfter.java
```java
public class StrategyAfter {
    public static void main(String[] args) {
        long price = 700000;
        Checkout checkout = new Checkout(new FestivalDiscount());
        checkout.print(price);                          // Festival 10%: Rs 630000
        checkout.setDiscount(new LoyaltyDiscount());    // swap the rule at run time
        checkout.print(price);                          // Loyalty Rs 20000: Rs 680000
        checkout.setDiscount(new CorporateDiscount());
        checkout.print(price);                          // Corporate 15%: Rs 595000
        checkout.setDiscount(new NoDiscount());
        checkout.print(price);                          // No discount: Rs 700000
    }
}

interface Discount {                                    // Strategy: the role every rule plays
    long apply(long price);
    String label();
}

class NoDiscount implements Discount {                  // ConcreteStrategy
    public long apply(long price) { return price; }
    public String label() { return "No discount"; }
}

class FestivalDiscount implements Discount {            // ConcreteStrategy
    public long apply(long price) { return price * 90 / 100; }
    public String label() { return "Festival 10%"; }
}

class LoyaltyDiscount implements Discount {             // ConcreteStrategy
    public long apply(long price) { return Math.max(0, price - 20000); }
    public String label() { return "Loyalty Rs 20000"; }
}

class CorporateDiscount implements Discount {           // ConcreteStrategy
    public long apply(long price) { return price * 85 / 100; }
    public String label() { return "Corporate 15%"; }
}

class Checkout {                                        // Context
    private Discount discount;                          // knows only the interface

    Checkout(Discount discount) { this.discount = discount; }

    void setDiscount(Discount discount) { this.discount = discount; }

    long total(long price) { return discount.apply(price); }   // delegation

    void print(long price) {
        System.out.println(discount.label() + ": Rs " + total(price));
    }
}
```

```java
public class DeliveryBefore {
    public static void main(String[] args) {
        DeliveryDesk desk = new DeliveryDesk();
        System.out.println(desk.charge("pickup", 12));    // 0
        System.out.println(desk.charge("home", 12));      // 600
        System.out.println(desk.charge("flatbed", 12));   // 2960
    }
}

class DeliveryDesk {
    long charge(String mode, int km) {
        if (mode.equals("pickup")) return 0;                    // customer collects at the showroom
        else if (mode.equals("home")) return 50L * km;          // driven to the door, Rs 50 per km
        else if (mode.equals("flatbed")) return 2000 + 80L * km; // on a truck, never driven
        else throw new IllegalArgumentException("unknown mode: " + mode);
    }
}
```

### DeliveryAfter.java
```java
import java.util.Map;

public class DeliveryAfter {
    public static void main(String[] args) {
        DeliveryDesk desk = new DeliveryDesk(Map.of(
            "pickup", km -> 0,
            "home", km -> 50L * km,
            "flatbed", new Flatbed(2000, 80)));
        System.out.println(desk.charge("pickup", 12));    // 0
        System.out.println(desk.charge("home", 12));      // 600
        System.out.println(desk.charge("flatbed", 12));   // 2960
        try {
            desk.charge("drone", 12);
        } catch (IllegalArgumentException e) {
            System.out.println(e.getMessage());           // unknown mode: drone
        }
    }
}

@FunctionalInterface
interface DeliveryCharge {                                // the Strategy
    long charge(int km);
}

record Flatbed(long base, long perKm) implements DeliveryCharge {   // a strategy with data
    public long charge(int km) { return base + perKm * km; }
}

class DeliveryDesk {                                      // the Context
    private final Map<String, DeliveryCharge> modes;

    DeliveryDesk(Map<String, DeliveryCharge> modes) { this.modes = modes; }

    long charge(String mode, int km) {
        DeliveryCharge c = modes.get(mode);
        if (c == null) throw new IllegalArgumentException("unknown mode: " + mode);
        return c.charge(km);
    }
}
```

```java
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;

public class SortStrategy {
    public static void main(String[] args) {
        List<Car> cars = new ArrayList<>(List.of(
            new Car("Nexon", 1250000), new Car("Tiago", 550000), new Car("Harrier", 1800000)));
        cars.sort(Comparator.comparingLong(Car::price));             // strategy 1: cheapest first
        System.out.println(cars);
        cars.sort(Comparator.comparingLong(Car::price).reversed());  // strategy 2: dearest first
        System.out.println(cars);
    }
}
```

### ModernStrategy.java
```java
import java.util.Map;

public class ModernStrategy {
    public static void main(String[] args) {
        long price = 700000;

        // 1. lambdas and a method reference: each one IS a Discount object
        Discount festival = p -> p * 90 / 100;
        Discount loyalty = Offers::loyalty;
        System.out.println(new Checkout(festival).total(price));   // 630000
        System.out.println(new Checkout(loyalty).total(price));    // 680000

        // 2. a record when the rule needs data (a configured percentage)
        System.out.println(new Checkout(new PercentOff(15)).total(price));   // 595000

        // 3. a registry: choose the strategy by name at run time, no if / else
        Map<String, Discount> offers = Map.of(
            "none", p -> p,
            "festival", festival,
            "loyalty", loyalty,
            "corporate", new PercentOff(15));
        for (String code : new String[] {"festival", "corporate", "festive"}) {
            Discount d = offers.getOrDefault(code, p -> p);    // unknown code: no discount
            System.out.println(code + " -> " + new Checkout(d).total(price));
        }
        // festival -> 630000
        // corporate -> 595000
        // festive -> 700000

        // 4. an enum when the set of rules is fixed and needs a name and a label
        for (Offer o : Offer.values())
            System.out.println(o + " (" + o.label + "): Rs " + new Checkout(o.rule).total(price));
        // NONE (No discount): Rs 700000
        // FESTIVAL (Festival 10%): Rs 630000
        // LOYALTY (Loyalty Rs 20000): Rs 680000

        // 5. strategies combine: festival first, then loyalty on the reduced price
        System.out.println(new Checkout(festival.andThen(loyalty)).total(price));   // 610000
    }
}

@FunctionalInterface
interface Discount {                                    // one abstract method: a lambda fits
    long apply(long price);

    default Discount andThen(Discount next) {           // default methods don't count
        return p -> next.apply(apply(p));
    }
}

record PercentOff(int percent) implements Discount {
    public long apply(long price) { return price * (100 - percent) / 100; }
}

class Offers {
    static long loyalty(long price) { return Math.max(0, price - 20000); }
}

enum Offer {
    NONE("No discount", p -> p),
    FESTIVAL("Festival 10%", p -> p * 90 / 100),
    LOYALTY("Loyalty Rs 20000", Offers::loyalty);

    final String label;
    final Discount rule;

    Offer(String label, Discount rule) { this.label = label; this.rule = rule; }
}

class Checkout {                                        // the Context does not change at all
    private final Discount discount;

    Checkout(Discount discount) { this.discount = discount; }

    long total(long price) { return discount.apply(price); }
}
```
