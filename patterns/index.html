Learn every design pattern by watching it run

All 23 classic (Gang of Four) patterns, from "never heard of it" to "can defend it in an interview". They are taught in five moves, easiest first: swap behaviour, create objects, wrap objects, make objects talk, compose structures. Every pattern starts from a painful car-dealership problem, is refactored step by step while the class diagram grows, runs in front of you call by call, and goes four levels deep: see it, build it, choose it, master it. Every program runs on a real JDK.
