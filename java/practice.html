Complexity cheat sheet

  
The time and extra space of every operation used in this course, in one table. n is the length of the String or array, m the length of the other argument, k the number of items added. Interviewers expect you to state these without thinking, and to know why (the notes column).

  

    
    
  

  

    
OperationTimeExtra spaceWhy / note

    
s.length(), s.charAt(i)O(1)O(1)Read from the backing byte[]; works for LATIN1 and UTF16 coders.

    
s.equals(t)O(n)O(1)Same reference, a different coder or a different length returns at once; otherwise it compares byte by byte.

    
s.hashCode()O(n) first callO(1)Cached in the hash field afterwards, so later calls are O(1). That is why Strings make good map keys.

    
s.compareTo(t)O(min(n, m))O(1)Stops at the first different char, or returns the length difference.

    
s.indexOf(t), s.contains(t)O(n·m) worstO(1)A naive scan (CPU-intrinsified), not KMP. Usually close to O(n) on real text.

    
s.indexOf(char), startsWith, endsWithO(n) / O(m)O(1)startsWith/endsWith only compare the prefix or suffix.

    
s.substring(a, b)O(b − a)O(b − a)Copies the range (since Java 7u6). Before that it shared the parent array.

    
s + t, s.concat(t)O(n + m)O(n + m)Always builds a new String, because Strings are immutable.

    
s += x inside a loop of k stepsO(k²)O(k) liveEach step copies everything so far. Use one StringBuilder: O(k) total.

    
toCharArray(), new String(char[]), String.valueOf(char[])O(n)O(n)Defensive copies in both directions.

    
toUpperCase, replace(char, char), strip, trimO(n)O(n)Returns this when nothing changes; otherwise a new String.

    
split(regex), replaceAll, matchesO(n) typicalO(n)Plus the cost of compiling the regex. split has a fast path for one plain character. Backtracking patterns can be much worse.

    
String.join, s.repeat(k)O(total)O(total)Output length: the sum of the parts, or n·k.

    
s.intern()O(n) averageO(1) or O(n)Hash the content, look it up in the StringTable; adds the reference if missing.

    
sb.append(x)O(1) amortized per charO(1) amortizedCapacity grows to old*2+2 (or what is needed), so copies are rare. Pre-size with new StringBuilder(n).

    
sb.charAt(i), sb.setCharAt(i, c), sb.length()O(1)O(1)Direct array access.

    
sb.insert(0, x), sb.deleteCharAt(0)O(n)O(1)Shifts every char after the position. At the end it is O(1).

    
sb.reverse()O(n)O(1)In place, and it keeps surrogate pairs (emoji) intact.

    
sb.toString()O(n)O(n)Copies into a new immutable String. Call it once, at the end.

    
a[i] read or write, a.lengthO(1)O(1)Address = base + i × element size; length is a field in the header.

    
Linear search, Arrays.toString, Arrays.equals, Arrays.fillO(n)O(1) / O(n)toString builds an O(n) String; the others need no extra space.

    
Insert or delete in the middleO(n)O(1) or O(n)Arrays are fixed size and contiguous: shift the tail, or copy into a new array.

    
clone(), Arrays.copyOf, System.arraycopyO(n)O(n)Shallow: an array of objects copies references, not objects.

    
Arrays.sort(int[]) (primitives)O(n log n)O(log n) to O(n)Dual-pivot quicksort; falls back to heap sort if recursion gets too deep, so no O(n²) worst case. Input made of long sorted runs is merged with an O(n) buffer instead. Not stable (it doesn’t matter for primitives).

    
Arrays.sort(T[]), list.sort (objects)O(n log n)O(n)TimSort: stable, and O(n) on input that is already sorted.

    
Arrays.binarySearchO(log n)O(1)Only correct on sorted input. Not found: -(insertion point) - 1.

    
Arrays.asList(arr)O(1)O(1)A fixed-size view that writes through to the array. List.of(arr) copies: O(n).

    
Arrays.deepEquals, deepToStringO(total cells)O(depth) / O(total)Recurses into nested arrays.

    
list.get(i), list.set(i, x)O(1)O(1)Backed by an Object[].

    
list.add(x) at the endO(1) amortizedO(1) amortizedGrows by about 1.5× when full, so the rare O(n) copy averages out.

    
list.add(0, x), list.remove(i)O(n)O(1)Shifts the tail with System.arraycopy.

    
list.contains(x), indexOf, remove(Object)O(n)O(1)Linear scan with equals. Need fast lookups? Use a HashSet.

    
Two pointers (reverse, palindrome, pair sum on sorted input)O(n)O(1)Each pointer moves at most n steps.

    
Sliding window (longest unique substring, window sum)O(n)O(1) or O(alphabet)Each index enters and leaves the window once.

    
Counting with int[26] / int[128]O(n)O(1)The array size is fixed by the alphabet, not by n.

    
Counting with a HashMapO(n) averageO(distinct)Average O(1) per get/put; slower than an array by a constant factor.

    
Prefix sum: build, then range queryO(n), then O(1)O(n)sum(l..r) = p[r + 1] − p[l].

    
Kadane (maximum subarray)O(n)O(1)Extend the current run or restart at this element.

    
Stack: brackets, decode stringO(n)O(n)Each char is pushed and popped at most once.

    
Sort, then two pointers or scanO(n log n)O(log n) to O(n)The sort dominates the cost.

    
Group anagrams with a sorted keyO(n·k log k)O(n·k)n words of length k. A count key (int[26]) makes it O(n·k).

    
Longest palindrome by expanding around centresO(n²)O(1)2n − 1 centres, each expands up to n/2.

    
All substrings, brute forceO(n³)variesO(n²) substrings, and checking or copying each one costs up to O(n). The baseline to beat with a window or hashing.

  

  
No operations match the filter.

  
Rule of thumb for n ≈ 105: O(n) and O(n log n) run instantly, O(n²) is about 1010 steps and times out, and O(n·m) indexOf is fine for normal text but not for adversarial input.

Memory Lab

  
Type Java statements and step through them while the JVM's memory draws itself: every stack frame with its variables, every object on the heap (with the String pool and the Integer cache shown separately), an arrow for every reference, and the console. Each step explains in plain English what Java just did: a literal reused from the pool, new forcing a fresh object, a reference copied into a method's frame, an object left with no references, and what System.gc() collects.

  
Why it exists: interview questions about == vs equals, the String pool, the Integer cache, aliasing and pass-by-value are all questions about where things live in memory. Seeing the arrows makes the answers obvious.

  
The Memory Lab needs JavaScript.

  
Supported: declarations and assignments of int long double boolean char String Integer StringBuilder and arrays; new; array initializers; a[i] = …; + - * / %; == != < >; String methods (equals length charAt substring intern toUpperCase concat …); StringBuilder append insert reverse toString; Integer.valueOf; clone; Arrays.toString/sort/fill; your own static methods with parameters and return; System.out.println; System.gc(). No if or loops yet: write the steps out. Every example's output matches real Java (checked on JDK 25). Ctrl + Enter steps.

Algorithm race

  
Pick two sorting algorithms and race them on the same array. Every bar is an element; you see each comparison and each write as it happens, with live counters, and the board explains why the winner won: O(n²) against O(n log n), the best case of insertion sort on nearly sorted data, the worst case of a naive quicksort on sorted input, and more.

  
Why it exists: "which sort would you use, and why?" is a classic interview question. Watching the same data sorted two ways turns Big-O from a formula into something you can see.

Lesson 01 sheet

  

    
Core
  • Immutable object, final class, java.lang
  • Literal → pool · new → heap · intern() → pool
  • Methods return new Strings: reassign

    
Compare
  • equals for content, == for references
  • "lit".equals(x) is null-safe
  • compareTo: char difference or length difference

    
Build & convert
  • StringBuilder in loops; StringBuffer only if threads share it
  • parseInt · String.valueOf · new String(arr)
  • Never arr.toString()

    
Gotchas
  • substring end is excluded
  • split takes a regex and drops trailing ""
  • Emoji = 2 chars · c - 'a' → 0..25

  

  
Rapid fire

  
"a,b,,".split(",").length?
2. Trailing empty strings are dropped.

  
'a' + 1?
98, an int. Cast with (char) to get 'b'.

  
"Apple".compareTo("apple")?
−32 ('A' is 65, 'a' is 97).

  
"1.2".split(".").length?
0. The dot is a regex that matches every character.

  
Which builder is thread-safe?
StringBuffer

  
Is b a rotation of a?
Same length and (a + a).contains(b).

  
Arrays.asList(new int[]{1, 2}).size()?
1. The list holds the int[] itself.

  
Arrays.binarySearch(new int[]{1, 3, 5}, 4)?
−3, which is -(insertion point 2) - 1.

  
Does grid.clone() copy the rows of a 2D array?
No. It is shallow, so the rows are shared. Clone each row for a deep copy.
