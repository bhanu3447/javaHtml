# Java course v1 — backup (2026-10-24)

The complete first version of the Java course, kept as one backup before the course was restarted from scratch
(user: "remove everything in the java, keep one backup, will start from scratch").

Nothing in this folder is loaded by the live site. It is a plain copy of the files as they were at git commit
`2b1d8df` (Responsive v40), which also holds the full history:

- `java/` — home page, the Playground / Mock interview / Big-O / Revise page (`practice.html`) and the eight lesson pages 00–07.
- `kb/` — the lesson texts (`lesson-00` … `lesson-07`), the practice-layer and course-tools notes, the site-internals notes and the two audit plans.
- `assets/labs/` — the five Java lab scripts (foundations, OOP, collections, analogy, sorting).
- `assets/js/practice-tools.js` — Memory Lab interpreter and Algorithm race.
- `assets/data/quiz-data.js`, `course-index.js` — the Java quizzes, recall prompts and the generated page index.
- `KB.md`, `CLAUDE.md` — the project notes of that version.

Engine files that stayed in place and are still used by the new course: `assets/css/course.css`, `assets/js/course.js`,
`assets/js/effects.js`, `assets/js/run-java.js`, `scripts/build-index.mjs`, and the whole SQL course.
